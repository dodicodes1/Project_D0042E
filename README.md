# Fault Detection in District Heating Systems using LSTM and Random Forest
## Project Overview (D0042E)

This project was developed as part of the course D0042E with the objective of implementing an AI workflow applicable in an engineering context. The engineering theme was Operations and Maintenance within district heating systems.

The project investigates how machine learning can be used for fault detection in district heating networks by comparing two different approaches:

* LSTM (Long Short-Term Memory) neural networks
* Random Forest classification models

## How to use
Run the file "LSTM_project.ipynb".
